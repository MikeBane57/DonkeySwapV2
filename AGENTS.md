# AGENTS.md

## Cursor Cloud specific instructions

DonkeySwap V2 is a Laravel 12 + React/Inertia app (shift-swap + bid-tools). It uses
**PHP 8.3** locally (CI uses 8.4), **Node 22**, and **SQLite** by default
(`DB_CONNECTION=sqlite` in `.env.example`). Standard commands live in `package.json`,
`composer.json` scripts, and `.github/workflows/ci.yml`; prefer those.

The startup update script already runs `composer install` and `npm ci`. The persisted
VM snapshot keeps `.env` (with `APP_KEY`) and `database/database.sqlite`. On a fresh
checkout those one-time steps are: `cp .env.example .env && php artisan key:generate &&
touch database/database.sqlite && php artisan migrate`.

### Running the app (two working modes)
- **Built assets (simplest):** `npm run build` then `php artisan serve` (no Vite needed).
- **Dev / HMR:** run Vite bound to a concrete host, not the default. `npm run dev` alone
  writes `http://[::]:5173` into `public/hot`, and the local Content-Security-Policy
  (`app/Http/Middleware/ContentSecurityPolicy.php`) only allows `script-src ...
  http://<request-host>:5173`, so `[::]` is blocked and the page renders blank. Start it
  as `npm run dev -- --host 127.0.0.1` and open the app at `http://127.0.0.1:8000`
  (host must match) for HMR to work. `composer dev` / `npm start` run server + Vite together.

### Gotchas
- **Wayfinder generated imports:** `@/routes`, `@/routes/*`, and `@/actions/*` are
  generated by the Vite Wayfinder plugin during `npm run dev`/`npm run build`. Before the
  first build, `npm run types:check` (tsc) reports many false `Cannot find module '@/routes'`
  errors. Run a build/dev once first. (Other tsc/eslint/prettier findings are pre-existing
  repo style/type issues, unrelated to setup; GH CI does not gate on `types:check`.)
- **Seeding:** `php artisan db:seed` (full `DatabaseSeeder`) currently fails — `WorkgroupSeeder`
  inserts a `regulatory` column that migration `2026_03_22_000001_remove_regulatory_from_workgroups`
  dropped. To get login-able users use `php artisan db:seed --class=UserSeeder`.
- **Login:** seeded users all use password `password`. `mike@example.com` is an `admin`
  (full access incl. bid-tools); `jordan@example.com` (manager), `sam@example.com` /
  `riley@example.com` (workers).
- **Feature gate:** `bid_tools` in `config/features.php` (default on) gates `/app/bid-tools`.

### Lint / test / build
- Backend lint: `composer lint:check` (Pint). Frontend: `npm run lint:check`,
  `npm run format:check`, `npm run types:check`.
- Tests: `./vendor/bin/pest` (or `php artisan test`), SQLite `:memory:` via `phpunit.xml`.
- Build: `npm run build`.
